# 星际快递员

一个可以直接打开 `index.html` 游玩的纯前端小游戏。你将操作机器人快递员在宇宙中穿梭，躲避陨石、收集能量晶体和多种能量道具，并尽可能获得更高分数。

## 玩法

- **PC**：方向键 或 `W A S D`
- **移动端**：使用页面下方的方向按钮
- **暂停**：点击“暂停 / 继续”按钮，或按 `P`
- **难度**：开始前可选择“轻松 / 普通 / 困难”

## 规则

- 收集蓝色晶体可获得 **10 分**
- 收集能量护盾可获得 **5 分**，并抵挡下一次陨石撞击
- 收集磁铁可获得 **8 分**，并在短时间内吸引附近奖励道具
- 收集维修包可获得 **12 分**，并回复 1 点生命；满生命时会获得额外分数
- 生存时间越长，分数越高
- 游戏会自动保存浏览器本地的 **历史最高分**
- 每 **15 秒** 自动提升 1 个等级，陨石会越来越快
- 撞到陨石会损失 1 点生命，生命归零则游戏结束

## 难度差异

- **轻松**：初始生命更多，移动更快，陨石更慢，适合熟悉玩法
- **普通**：标准节奏
- **困难**：生命更少，陨石更快，但持续得分倍率更高

## 文件结构

- `index.html`：页面入口
- `style.css`：界面样式
- `game.js`：游戏逻辑
- `assets/`：小游戏图片资源（SVG）
