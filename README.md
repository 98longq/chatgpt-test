# 星际快递员

一个可以直接打开 `index.html` 游玩的纯前端小游戏。你将操作机器人快递员在宇宙中穿梭，躲避陨石、收集能量晶体，并尽可能获得更高分数。

## 玩法

- **PC**：方向键 或 `W A S D`
- **移动端**：使用页面下方的方向按钮
- **暂停**：点击“暂停 / 继续”按钮，或按 `P`

## 规则

- 收集蓝色晶体可获得 **10 分**
- 生存时间越长，分数越高
- 每 **15 秒** 自动提升 1 个等级，陨石会越来越快
- 撞到陨石会损失 1 点生命，生命归零则游戏结束

## 文件结构

- `index.html`：页面入口
- `style.css`：界面样式
- `game.js`：游戏逻辑
- `assets/`：小游戏图片资源（SVG）

## 在线游玩建议
